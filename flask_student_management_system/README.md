# Flask Student Management System

A beginner-friendly Python full-stack CRUD application using Flask, HTML, CSS, and SQLite.

## Features
- Add, list, edit, and delete student records
- Search by name, email, or course
- SQLite database
- Parameterized SQL queries
- Responsive interface

## Stack
Python, Flask, SQLite, HTML, CSS, JavaScript (browser-side)

## Run locally

### Windows
```bash
python3 -m venv .venv
source .venv/bin/activate
python app.py
```

Open http://127.0.0.1:5000/

The SQLite database is created automatically on first run.
